Meus projetos

Projeto TCC Projeto em equipe · 2026

GeoSync

Plataforma de rastreamento e logística que integra um módulo IoT a uma aplicação web em Laravel 12 e a um aplicativo mobile em Flutter, para coletar, sincronizar e visualizar dados de localização de remessas e entregas.

Plataforma web

  • Laravel 12 com PHP e Vite
  • Autenticação com Laravel Sanctum
  • Login social com Laravel Socialite
  • Processamento assíncrono com filas

Aplicativo mobile

  • Flutter com sincronização offline
  • Localização em segundo plano
  • QR Code e bloqueio biométrico
  • Rotas otimizadas e assinatura digital

Módulo IoT

  • Coleta dados de localização
  • Integra com a plataforma de gestão
  • Dados exportáveis em CSV e GeoJSON

Banco de dados

  • MySQL com dump do esquema
  • Dados de remessas, motoristas e clientes
  • Sincronização incremental com o servidor
